# Raio-X da Carteira de Crédito — Teste Técnico Analista de Portfólio

## Objetivo
Responder ao Diretor de Crédito:
1. Por que a inadimplência (Over 90) da carteira piorou recentemente?
2. Qual produto/modalidade está puxando o LA das safras recentes para baixo?

## Estrutura
```
data/raw/    CSVs originais (imutáveis)

scripts/     Carga dos CSVs para o SQLite

entrega/     E-mail ao Diretor
docs/        Enunciado do desafio
```
